    Welcome! Let’s build your first seating chart

    1. Set up the bus. Rows, seats per bench, door side and wheelchair area.
    2. Add students. Import a CSV (name,school) or type names in one at a time.
    3. Seat them. Drag a student onto a seat, or tap a student then a seat.
    4. Set a baseline before you make changes, then export a PDF with the change log.
    Legend: badges and colors
    • ★ Car seat: this seat has a 5-star belt.
    • H Harness attachment on this seat.
    • ⚑ Warning: the student needs a seat feature or area this seat does not have.
    • Gold double border: seat changed since the baseline.
    • Red dashed student: has a warning.
    • Student color: one color per school.
    • Blue seat: wheelchair spot.
    • EXIT Emergency window exit.
    • While dragging: green is an empty seat that works, amber is a seat that would trigger a warning, blue is a swap.
